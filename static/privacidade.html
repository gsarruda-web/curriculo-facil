Aviso de Privacidade

O Currículo Fácil utiliza as informações fornecidas exclusivamente para montar o currículo solicitado pelo próprio usuário.

Dados solicitados

São solicitadas apenas informações necessárias ou úteis ao currículo, como nome, contato, cidade, formação, cursos e experiências profissionais. O sistema não solicita CPF, RG, dados bancários ou nome dos pais.

Armazenamento

Nesta versão, os dados preenchidos não são gravados em banco de dados. O documento é criado temporariamente no servidor, entregue ao usuário e removido após o envio.

Endereço

O endereço completo é opcional. Para a maioria dos currículos, cidade e estado são suficientes.

Responsabilidade pelas informações

O usuário deve revisar o currículo antes de utilizá-lo. O sistema não deve inventar experiências, formações ou qualificações.
